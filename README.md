# ⚔️ Projeto 200 — Jornada do Desenvolvedor

Repositório dedicado à prática intensiva de lógica de programação com JavaScript, focado no domínio de arrays e objetos por meio de 200 desafios progressivos.

O objetivo não é apenas resolver exercícios, mas desenvolver raciocínio lógico, autonomia e segurança para escrever código sem depender de soluções prontas.

## 🎯 Objetivos

- Fortalecer a lógica de programação.
- Dominar os principais métodos de arrays e objetos em JavaScript.
- Desenvolver a capacidade de resolver problemas de forma independente.
- Aprender a escolher a abordagem mais adequada para cada problema.
- Consolidar os fundamentos necessários para evoluir no desenvolvimento back-end.

## 📚 Estrutura do projeto

O projeto está dividido em duas etapas complementares, com 100 desafios cada, realizadas em paralelo.

### 🗡️ Etapa 1 — Arrays

**100 desafios** para praticar manipulação de listas, busca, filtragem, transformação e análise de dados.

Conteúdos trabalhados:
- Acesso e manipulação de elementos.
- Métodos como `map()`, `filter()`, `find()` e `some()`.
- Métodos como `reduce()`, `includes()` e `sort()`.
- Condicionais, loops e funções.
- Resolução de problemas com listas de dados.

### 🛡️ Etapa 2 — Objetos

**100 desafios** para aprofundar o trabalho com estruturas de dados e informações organizadas em propriedades.

Conteúdos trabalhados:
- Criação e manipulação de objetos.
- Acesso, alteração e remoção de propriedades.
- Iteração sobre propriedades e valores.
- Métodos como `Object.keys()`, `Object.values()` e `Object.entries()`.
- Combinação de arrays e objetos.
- Resolução de problemas com dados estruturados.

## 🧠 Regras da jornada

1. Tentar resolver cada desafio de forma independente antes de buscar ajuda.
2. Evitar copiar soluções prontas.
3. Utilizar dicas progressivas quando houver dificuldade.
4. Testar o código com diferentes entradas e situações.
5. Priorizar a compreensão da solução, não apenas o resultado.
6. Registrar as soluções e manter um histórico de evolução.
7. Revisitar os desafios sempre que necessário para reforçar o aprendizado.
